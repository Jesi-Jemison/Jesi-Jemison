**🚀 Current Projects**

⚙️ TALOS — Data Quality Sentinel

Python · pandas · Streamlit · pytest

TALOS is a lightweight Python application designed to inspect questionable datasets before they make their way into analysis.

It checks for issues including:

missing values

duplicate records

inconsistent categories

structural anomalies

suspicious identifiers

statistical outliers

It then produces an explainable Dataset Integrity Score and shows what was found, why it may matter and what deserves investigation.

A guardian at the gate between messy data and trustworthy analysis.
